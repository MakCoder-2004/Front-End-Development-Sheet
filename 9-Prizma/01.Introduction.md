# 01. Introduction

Prisma is a modern ORM (Object Relational Mapping) tool for Node.js and TypeScript. It provides a type-safe database client, auto-generates SQL migrations, and supports PostgreSQL, MySQL, SQLite, SQL Server, and MongoDB. Prisma improves productivity, reduces runtime errors, and brings a better developer experience.

### Why Use Prisma?

* Type safety and auto-completion
* Easy schema modeling
* Powerful migrations system
* Interactive Prisma Studio
* Works seamlessly with TypeScript

### Core Components:

* **Prisma Client**: Type-safe query builder for database access.
* **Prisma Migrate**: Declarative migration system.
* **Prisma Studio**: GUI for browsing and editing database content.
* **Prisma Schema**: Describes your data models and relationships.

### Install Prisma:

```bash
npm install prisma --save-dev
npx prisma init
```

This creates a `prisma` folder with a `schema.prisma` file and a `.env` file for the database URL.
