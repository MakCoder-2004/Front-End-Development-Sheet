

# 04. PrismaStudio

Prisma Studio is a web-based GUI that allows you to visually inspect and manipulate the data in your database.

### Start Prisma Studio:

```bash
npx prisma studio
```

This opens a local browser window where you can:

* View all models and records
* Add, edit, and delete entries
* Search and filter data

### Example Use Case:

You created a `User` and `Post` model and populated them with seed data. With Prisma Studio, you can:

* Easily confirm relationships between models (e.g. User-Post)
* Edit user names or post content inline
* Quickly debug issues in your database

Prisma Studio is ideal for both development and QA stages.
