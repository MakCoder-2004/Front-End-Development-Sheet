
# 02. PrismaClient

The Prisma Client is a type-safe database client auto-generated based on your `schema.prisma`. It allows you to interact with your database using JavaScript or TypeScript.

### Basic Setup:

```bash
npx prisma generate
```

```ts
import { PrismaClient } from '@prisma/client';
const prisma = new PrismaClient();
```

### Example: Fetch All Users

```ts
const users = await prisma.user.findMany();
console.log(users);
```

### Example: Create a New User

```ts
const newUser = await prisma.user.create({
  data: {
    name: 'John Doe',
    email: 'john@example.com'
  }
});
```

### Example: Update User

```ts
const updatedUser = await prisma.user.update({
  where: { id: 1 },
  data: { email: 'new@example.com' }
});
```
