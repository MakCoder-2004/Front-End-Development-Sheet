# Fonts in Next.JS

- Next.js has most of Google Fonts
  
## How to use ?!
```tsx
import { FontName } from "next/font/google";

const bebasFont = Bebas_Neue({
    subsets: ["latin"],
    weight: "400",
})

const Home = () => {
    return(
        <div>
            <h1 className={`${bebasFont}`}>Hello World!</h1>
        </div>
    )
}
```
