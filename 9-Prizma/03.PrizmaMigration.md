
# 03. PrismaMigration

Prisma Migrate helps you manage your schema changes over time with versioned migration files.

### Workflow:

1. Edit your `schema.prisma` file.
2. Run migration:

```bash
npx prisma migrate dev --name init
```

3. Prisma creates SQL migration files and updates your database schema.

### Example: Adding a New Model

```prisma
model Post {
  id        Int      @id @default(autoincrement())
  title     String
  content   String?
  published Boolean  @default(false)
  author    User     @relation(fields: [authorId], references: [id])
  authorId  Int
}
```

Then run:

```bash
npx prisma migrate dev --name add-post-model
```

### Useful Commands:

* `npx prisma migrate dev`: Apply migrations in dev.
* `npx prisma migrate reset`: Reset DB and reapply migrations.
* `npx prisma db push`: Push schema changes without generating migration (dev only).
