# Backend Development with Next.js

Next.js is a full-stack React framework that allows building both frontend and backend logic in a single application. It supports building API routes using its built-in API routing system, enabling server-side operations such as database access, authentication, and more.

## 📁 API Routes in Next.js

API routes allow you to create RESTful endpoints within the `pages/api` directory. Each file in this directory maps to an endpoint.

### Example File Structure:

```
/pages
  /api
    users.js         // => /api/users
    users/[id].js    // => /api/users/:id
```

## 📌 HTTP Methods

### 1. GET

Used to retrieve data from the server.

````ts
// /app/api/movies/route.ts (App Router format)
export async function GET() {
  return Response.json(movies);
}
```js
// /pages/api/users.js
export default async function handler(req, res) {
  if (req.method === 'GET') {
    try {
      const users = [
        { id: 1, name: 'Alice' },
        { id: 2, name: 'Bob' }
      ];
      res.status(200).json(users);
    } catch (error) {
      res.status(500).json({ error: 'Failed to fetch users' });
    }
  } else {
    res.status(405).end(); // Method Not Allowed
  }
}
````

### 2. POST

Used to send new data to the server (e.g., creating a resource).

````ts
// /app/api/movies/route.ts (App Router format)
export async function POST(req: Request) {
  let movie = await req.json();

  const newMovie = { ...movie };
  movies.push(newMovie);
  return new Response(JSON.stringify(newMovie));
}
```js
// /pages/api/users.js
export default async function handler(req, res) {
  if (req.method === 'POST') {
    try {
      const { name } = req.body;
      const newUser = { id: Date.now(), name };
      res.status(201).json({ message: 'User created', user: newUser });
    } catch (error) {
      res.status(500).json({ error: 'Failed to create user' });
    }
  } else {
    res.status(405).end();
  }
}
````

### 3. PATCH

Used to partially update a resource.

```js
// /pages/api/users/[id].js
export default async function handler(req, res) {
  const { id } = req.query;

  if (req.method === 'PATCH') {
    try {
      const { name } = req.body;
      res.status(200).json({ message: `User ${id} updated`, name });
    } catch (error) {
      res.status(500).json({ error: 'Failed to update user' });
    }
  } else {
    res.status(405).end();
  }
}
```

### 4. DELETE

Used to delete a resource.

```js
// /pages/api/users/[id].js
export default async function handler(req, res) {
  const { id } = req.query;

  if (req.method === 'DELETE') {
    try {
      res.status(200).json({ message: `User ${id} deleted` });
    } catch (error) {
      res.status(500).json({ error: 'Failed to delete user' });
    }
  } else {
    res.status(405).end();
  }
}
```

## 🔍 URL Query Parameters

Query parameters are accessible via `req.query`.

```js
// /pages/api/search.js
export default async function handler(req, res) {
  try {
    const { keyword } = req.query;
    res.status(200).json({ message: `Searching for ${keyword}` });
  } catch (error) {
    res.status(500).json({ error: 'Search failed' });
  }
}

// Example: /api/search?keyword=nextjs
```

## ⚙️ Middleware

Middleware runs before a request is completed, allowing tasks like authentication, logging, etc.

### Example Middleware:

```js
// /middleware.ts (Next.js 13+ with app directory)
import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';

export function middleware(request: NextRequest) {
  const { pathname } = request.nextUrl;

  if (pathname.startsWith('/api/private')) {
    const token = request.headers.get('authorization');
    if (!token) {
      return new NextResponse(JSON.stringify({ error: 'Unauthorized' }), { status: 401 });
    }
  }
  return NextResponse.next();
}

// In next.config.js
module.exports = {
  middleware: ["/api/private/:path*"],
};
```

## ✅ Summary Table

| Method | Purpose         | Accessed by             |
| ------ | --------------- | ----------------------- |
| GET    | Retrieve data   | `req.query`             |
| POST   | Create resource | `req.body`              |
| PATCH  | Update resource | `req.body`, `req.query` |
| DELETE | Remove resource | `req.query`             |

## 🧪 Testing Your API

You can test API routes using tools like:

* Postman
* curl
* fetch from the frontend:

```js
// Example fetch
const res = await fetch('/api/users', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ name: 'Charlie' })
});
const data = await res.json();
```
